Aerovant Academy logo files used by the site.

  academy-logo-blue.png    blue logo, for light backgrounds (header on every page)
  academy-logo-white.png   white logo, for dark backgrounds (footer on every page)

Both are the official PNGs with the empty margin trimmed, exported at 240px height.
To replace one, keep the same file name, a transparent background and no empty margin
around the artwork. Sizes are set in css/academy.css under ".brand__logo".

The favicon (logo only no bg.png) already lives in this folder on the live site. Keep it.
